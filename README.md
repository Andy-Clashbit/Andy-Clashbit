## `whoami`

> **Curious mind. Automation enthusiast. Builder of digital things.**

I explore the intersection of AI, developer tooling and automation.
I like systems that do useful work, tools that remove friction,
and experiments that turn a rough idea into something real.

- `AI / Agents` — experimenting with AI tools and autonomous workflows
- `Automation` — scripts, repeatable processes and less manual busywork
- `Self-hosting` — Linux, Docker and services under my control
- `Open source` — discovering projects, learning from code and building things
- `Beyond the terminal` — music, games and creative experiments
