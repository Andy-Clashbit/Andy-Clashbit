# ADR-0001: Архитектура компонентов профиля и workflow для Bomberman Graph

- **Статус**: Принято
- **Дата**: 2026-10-27
- **Контекст**:
  Пользователь запросил создание уникального GitHub Profile README для аккаунта `Andy-Clashbit`. Ключевые требования: интеграция шапки `capsule-render`, интеграция аркадной визуализации графа активности `Bomberman` из `abozanona/pacman-contribution-graph`, внедрение пиксельной анимации `MultiTaskingGuy` из `hackwithdev/pixelartgifs`, нестандартные бейджи иконки, и стильное описание в стиле гитхаб-разработчика.
- **Решение**:
  1. **Безопасность**: Отказ от передачи персонального токена в чат; генерация локальных файлов конфигурации и использование стандартного `secrets.GITHUB_TOKEN` внутри GitHub Actions с разрешением `contents: write`.
  2. **Генерация Bomberman SVG**: Развертывание GitHub Action `abozanona/pacman-contribution-graph@main` с параметром `games: 'bomberman'` и публикацией в обособленную ветку `output` через `crazy-max/ghaction-github-pages`.
  3. **Стиль шапки**: Использование `capsule-render` с типом `soft` в глубокой темной палитре (`#0D1117` / `#161B22`) с анимацией `twinkling` и акцентным бордером `#58a6ff`.
  4. **Иконки технологий**: Замена стандартных однотипных бейджей Shields.io на современные скругленные иконки `skillicons.dev` и кастомные минималистичные бейджи.
  5. **О себе**: Оформление в виде хакерского терминала / Neofetch с акцентом на инди-геймдев (`RPG-2.0`) и автоматизацию (`Sortir`).
- **Последствия**:
  - Плюсы: Профиль выглядит визуально цельным, динамичным и нетипичным; не требует внешних серверов; SVG обновляется автоматически раз в сутки; токен пользователя остается в безопасности.
  - Минусы: Для работы Bomberman SVG требуется первичный запуск GitHub Action и включение прав на запись во вкладке настроек репозитория.
